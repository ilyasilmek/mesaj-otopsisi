# Mesaj Otopsisi

Mesajların altında yatan anlamı eğlenceli bir otopsi raporuna dönüştüren, önce PWA olarak geliştirilecek sosyal AI uygulaması.

## Ürün hedefi

Ekran görüntüsü veya metin → konuşma çıkarımı → bağlam analizi → mizahi rapor → paylaşılabilir sonuç kartı.

## Geliştirme yaklaşımı

- İlk sürüm: ücretsiz, reklamsız MVP
- İlk platform: responsive web + PWA
- Sonraki platformlar: iOS / Android
- AI anahtarları yalnızca server tarafında tutulur
- Kullanıcı görselleri mümkün olduğunca geçici işlenir ve kalıcı arşivlenmez
- UI ile analiz mantığı birbirinden ayrılır
